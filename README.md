# Camera Follow Scripts CSharp
A collection of Unity C# camera follow scripts for 2D and 3D.




简体中文 · [English](README.en.md)

> [!IMPORTANT]
> 这个仓库持续更新 Unity 2D / 3D 的相机跟随 C# 脚本，希望对你有帮助。

## 📜 脚本列表
| 脚本名称 | 方式 | 支持版本 |
| ---- | ---- | ---- |
| Simple Follow | 硬跟随把相机位置直接设为角色位置加偏移，不做任何平滑 | Unity2D |
| Deadzone Follow| 死区跟随目标在矩形框内不动，超出才推镜头 | Unity2D |

## 🚀 使用方法
1. 下载脚本，放入Unity项目
2. 挂载到Camera物体上
3. 在Inspector填入Target（跟随目标）
